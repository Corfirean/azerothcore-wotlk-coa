INSTALL / LAUNCH
----------------
Close the game first. Stop_All_Server.bat.

1. Extract both zips into the repack (next to Start_All_Server.bat).
2. Run CoA-Custom\Install-Custom.bat
3. Play.

  Without bots:     Start_All_Server.bat
  With bots:        CoA-Bots\Start_All_Bots.bat
  Root aliases:     StartAllServer.bat
                    StartAllServerWithBots.bat
  Typos:            Did_You_Mean.bat startallserverwithbots
                    prints  Did you mean this: CoA-Bots\Start_All_Bots.bat

Wrong folder during install:
  Did you mean this: the folder that contains Start_All_Server.bat
